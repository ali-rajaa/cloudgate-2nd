The steps

{% include steps-switch.html id="hiw-steps" %}
{% include section-head.html title="Every listing has four settings" id="listing-title" %}
  • {% include icon.html name="store" size=20 %}

    Quantity

    One bulk lot, or single items.

  • {% include icon.html name="receipt" size=20 %}

    Price

    From Rs 1,000 up to half of retail, or Rs 0 to give it away.

  • {% include icon.html name="users" size=20 %}

    Who can claim

    Organizations, the public, or both. At launch, organizations only.

  • {% include icon.html name="clock" size=20 %}

    Pickup window

    At least 30 minutes, set by the vendor.

{% include section-head.html title="Paying and collecting" id="pay-title" %}
{% include icon.html name="key" size=22 %}

A code for every pickup

Each claim gets a 4-digit code. The vendor checks it before handing anything over.

{% include icon.html name="clock" size=20 %}

Pay within 30 minutes

Or the listing goes back for others to claim.

{% include icon.html name="heart" size=20 %}

Rs 0 listings

Claim and collect. Nothing to pay.
